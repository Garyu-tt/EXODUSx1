# EX-005 integrated store trace on Switch

Build `make -f Makefile.store` in this directory using devkitA64/libnx. The paired CI artifact includes separately named baseline and candidate NROs, SHA256SUMS and exact build provenance. Place each in its own hbmenu directory; retain the existing `/switch/exodus-page-probe/` CSV directory. Press Y to run; + exits. Reports `ex005-store-baseline.csv` and `ex005-store-candidate.csv` do not overwrite earlier microbenchmarks. Each run has seven trials, 32768 operations per trial. Correctness is checked against independent raw oracle, full-page restoration, fingerprints, alias equivalence, slab index and minimum hot/cold coverage. Timer is ARM system counter, not CPU cycles. Repeat AB then BA, archive first CSVs before repeating. The synthetic trace exercises caller-owned store APIs only; not game FPS or system-wide memory.
