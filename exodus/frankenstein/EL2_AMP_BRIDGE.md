# EL2 to AMP1 bridge reference
Separate QEMU system Cortex-A57 EL0/EL2 and QEMU Linux user-mode Cortex-A9 authority. EL0 SVC enters real EL2, which calls the unchanged AMP1 codec and transmits frames via QEMU PL011 serial. Host harness relays bytes without generating replies (negative control deliberately corrupts one reply). The authority is the existing synthetic peer. Test 128 identity requests plus exit intent, full-width task ID, sequence crosses 2^32, selected register preservation, unsupported opcode, corrupted reply rejection, bounded guest polling and host watchdog. No physical ADSP, FreeBSD syscall, shared-memory mapping, MMU isolation, Horizon coexistence or console deployment. Single trusted fixture only; not a production monitor. UART/link addresses apply only to QEMU virt. Next gate: protected memory and real inter-domain transport/authority. Refs #103 #105 #350 #352.

## R02 first CI failure and diagnostic correction

## Alignment fault diagnosis
Job 140143319868 reported a real same-EL data abort ESR 0x96000021 (alignment fault), FAR 0x4008183e, ELR 0x40081358 before READY. The guest emitted FAIL. With MMU off, ordinary C accesses must not rely on unaligned normal-memory behavior. Build the bare-metal AArch64 code with -mstrict-align and include annotated disassembly on failure. This targets the observed fault; exact instruction in the previous binary and success of the correction are not yet verified.
