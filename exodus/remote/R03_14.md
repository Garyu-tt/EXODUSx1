# R03.14 native TCP loopback admission

Tracks #89, based on the physically exercised #138. Independent of the
experimental TLS port #141. A locally initiated diagnostic binds exclusively
to 127.0.0.1 on an ephemeral port, connects a second local socket, and exchanges
an eight-byte marker in both directions. All descriptors are nonblocking;
polls and transfer attempts are bounded. Closes all descriptors and releases
libnx sockets on success or failure. No LAN listener, public network request,
credentials, remote authorization or unencrypted remote EXR transport.

Stage 1: socket service init; 2: listener creation; 3: bind/listen;
4: client connect; 5: accept/loopback peer verification; 6: connect completion;
7: client to server; 8: server to client; 0: success.

Build uses the existing native workflow. This is a source change, not a
verified build or hardware result. Test by launching the new NRO locally,
pressing A, recording Native TCP loopback and stage, then pressing Plus.
A PASS confirms only local TCP behavior, not LAN reachability or TLS.
