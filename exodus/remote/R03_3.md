# R03.3: TCP loopback reference server

Tracks #89; stacked on #98. Host POSIX C11/OpenSSL 3 reference only.
Explicit foreground start, IPv4 loopback only, ephemeral port, one active
connection, nonblocking sockets, five-second handshake deadline, 60-second
session lifetime, 100 ms poll ticks, SIGINT/SIGTERM stop. R03 framing and
session limits apply. Local owner supplies a CA, server identity and exact
paired client certificate at startup. Static read-only ACL: discovery/status.
Status explicitly identifies the host reference; no actual Switch telemetry.
Stop/restart to change the ACL; no dynamic pairing or background service.

From exodus/remote:
    cc -std=c11 -Wall -Wextra -Werror -pedantic -fsanitize=address,undefined -no-pie loopback_server.c -o /tmp/exr-server $(pkg-config --cflags --libs openssl)
    python3 test_loopback.py /tmp/exr-server

Local GCC 14.2/OpenSSL 3.5.7: passed after correcting test CA key usage
extensions (certificate checks remain enabled). Tests used real loopback TCP
and ephemeral certificates, including an unpaired client signed by the same CA,
no certificate, fragmented/coalesced requests, ACL, malformed frame, partial
frame and handshake timeouts, reconnect and SIGTERM. Server/session source
was tested with an exact session header and semantically equivalent local
reconstructions of gate/wire/TLS headers, not a full Git checkout. Repository
CI and exact-checkout run remain required. No production credentials generated.
