# EXODUS Remote R03: EXR/1 framing

Tracks #89; stacked on #92. Transport-independent stream framing, not a server.
No network listener, TLS/SSH library, pairing or credential validation is included.
Only pass an already authenticated encrypted stream to this adapter; never
bind it directly to a raw network socket. Session state is trusted local data.

Header: 8 bytes: EX magic, version 1, status (0 in request), unsigned
big-endian payload length, two zero reserved bytes. Request body is an exact
operation ID (1–32 bytes); response body at most 511 bytes. Error bodies empty.
The caller initializes connection state to zero, uses one per connection and
serializes access; reads local session state and monotonic milliseconds on each
feed/idle tick, loops over unconsumed bytes and closes on EXW_CLOSE. Never reuse
closed state. Use bounded input buffers, write deadlines and connection quotas.
Defaults: eight complete requests per fixed one-second window per connection,
three seconds from first byte to complete frame. This permits bursts at window
boundaries and is not a global rate limiter. Transport must independently
bound connections, idle lifetime, handshake costs, provider execution time and
output buffering. Re-check authorization before sending a queued reply.
On revocation/expiry/clock regression or invalid header, close; no resync.
