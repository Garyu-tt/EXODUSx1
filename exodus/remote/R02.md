# Remote R02: read-only telemetry

Stacked on R01 (#90), tracks #89. This provider does not add a listener or authenticate clients.
The caller supplies the reviewed mask; the provider probes only reviewed operations.
On host builds only discovery can be available; on Switch PSM, SVC and SD filesystem results determine availability.
Refresh the probe after resume or a provider failure. A failed request returns no fabricated telemetry.
The process memory limit/usage is not system-wide RAM. SD totals are for SD only. No NAND access, writes or privileged commands.

PSM/FS API signatures checked against libnx b156b4774fb2df7b93402169509266da7547fc4c. SVC calls follow the terminal adapter (#82).
PSM and opened SD handles are cleaned up on failure and success. Caller serializes access and provides the existing libnx FS service lifetime.
