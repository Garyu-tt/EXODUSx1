# R20 USB lifetime model

Independent C++17 UsbLifetime separates registry and generation-specific I/O serialization. Retirement waits for an in-flight callback, marks the generation inactive, then removes it from the registry. Context memory survives until the last lease is released. Later generations cannot reactivate old leases. Context destruction must be host-only after physical detach; callbacks must not reenter the controller or leak references beyond the callback. Bounded transport cancellation, admission of new I/O while retirement waits, lock order, native devoptab lifetime and physical detach are still open. This model is not yet integrated with UsbProvider or libusbhsfs; the upstream driver was not patched.
