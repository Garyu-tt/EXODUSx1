# EXODUS visual identity

Owner-approved direction, 2026-11-24: second concept with white EXODUS wordmark, violet diagonal X, violet/ice-blue orbital arc, star and dark background. First cyan portal/hexagonal concept was not selected.

## Asset plan

- Standalone emblem and wordmark, transparent PNG and SVG masters.
- Launcher icon, monochrome and small-size variants, favicon.
- Boot/splash screen (16:9), desktop wallpaper, README and social banner.
- Integrate into launcher and desktop UI with responsive layout.

Use the selected visual direction consistently. Avoid copying Nintendo trademarks; avoid excessive effects at small sizes. EXODUS is a system environment around Horizon rather than a conventional standalone OS.

Status: visual direction accepted; individual asset derivatives and integration are pending verification.
